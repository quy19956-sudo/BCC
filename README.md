# Bộ Công Cụ Y Khoa — BẢN CÔNG KHAI 3.9.4

Bản này dùng để đưa lên GitHub Pages công khai, đã đồng bộ phần lõi và các công cụ công khai từ bản 3.9.4.

## Không đưa lên bản public
Bốn công cụ riêng tư vẫn được giữ ngoài gói phát hành:
- Tính ngày lĩnh
- Quản lý chuyển khoản
- Đánh giá tăng trưởng trẻ em
- Tính sữa & theo dõi bé

Khu vực Sao lưu/Khôi phục cũng tiếp tục được ẩn trên giao diện web công khai.

## Giao diện
- Giữ `win98-theme.css` và phong cách Windows 98 + MiSans.
- Giữ `desktop-theme.css` + `desktop-theme.js` để tối ưu desktop/laptop.
- Mobile vẫn dùng bố cục co giãn hiện có.

## Cập nhật 3.9.4
Các trang công khai và phần lõi dùng phiên bản mới từ bộ mã nguồn 3.9.4, gồm runtime, đồng bộ nhanh, tra thuốc/offline, LDL-C / HDL-C và các sửa lỗi liên quan.

Mở `index.html` qua GitHub Pages.
